# news-Article-recommendation-system
Overview
This project is a News Article Recommendation and Ranking System developed using Python and Streamlit.

The system recommends news articles based on user interests using TF-IDF Vectorization and Cosine Similarity.

**Features**
✅ News Search

✅ Personalized News Recommendations

✅ News Ranking System

✅ Trending News Page

✅ Analytics Dashboard

✅ Word Cloud Visualization

✅ Category Distribution Charts

✅ Search History

**Technologies Used**
- Python
- Streamlit
- Pandas
- Scikit-Learn
- Matplotlib
- Plotly
- WordCloud
  
**Recommendation Technique**
- TF-IDF Vectorization
- Cosine Similarity
- Ranking Score Calculation
- Dataset
- Kaggle News Category Dataset

**Dataset Link:**

https://www.kaggle.com/datasets/rmisra/news-category-dataset
